Was der Agent tut

{{ d.where }}{{ d.what }}

Der Agent schreibt nie selbst nach TANSS. Entwürfe landen im Textfeld, Vorschläge werden erst mit „Freigeben“ ausgeführt.

Stil der Leistungstexte

Gilt für „Aus dem Verlauf entwerfen“ und die Vorschläge des Tagesassistenten – nicht für Mail- und Kommentarentwürfe, das ist eine andere Textsorte. Höchstens 3 Beispiele: mehr verdrängen im Prompt das Material, um das es eigentlich geht.

Eigene Musterbeispiele In den Zeiten können Sie einen gebuchten Text mit „als Beispiel“ hierher übernehmen.

Bausteine

Wiederkehrende Arbeit, die nirgends eine Spur hinterlässt – Mail, Monitoring, Triage. Unter jeder Lücke im Tag wird angeboten, was hineinpasst; die Dauer ist eine Spanne, aus der die Lücke das Passende nimmt. Höchstens 8 Stück.
